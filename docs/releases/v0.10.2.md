# Harness Slides 0.10.2

A deck now has a direction, and each content slide has a brief. The compiler
enforces both.

- **Direction, decided once:** the focal color, the neutral, what each other
  color stands for, and an optional motif. Fills come only from that set, and
  boxes start neutral.
- **Brief, per slide:** the relation between the slide's parts, its focal node
  and its rhythm. The relation must be drawn: edges or chevrons for order, edges
  for dependency, nesting or layers for hierarchy, a box holding its members for
  membership, side by side for contrast, intersecting shapes for overlap, the
  metric role for quantity.
- **One emphasis:** the compiler colors the focal node and refuses any other node
  in the focal color.
- **Readable text by default:** text on a dark fill takes a readable color unless
  the author set one.
- **Every broken rule in one pass:** validation reports each slide that needs a
  change, as fit errors already did.
- **New preview findings:** a deck with no direction, a slide with no brief, four
  dense slides in a row, a title that reads as a label.

Compositions without a direction or briefs compile as before.

Current public guidance requires runtime 0.10.2.

## Verification

Unit tests cover each rule. The 25-slide test deck was annotated with a direction
and briefs: the rules flagged ten slides in one pass, including decorative use of
the focal and category colors, and the corrected deck was previewed through
Google and inspected by eye. The combined Tart gate was not run.
