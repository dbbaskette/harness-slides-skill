# Harness Slides 0.10.0

New slides in a brand template are now composed, not hand-placed. The agent
describes each slide's structure (rows, columns, grids, freely placed nodes,
boxes, text, icons, images and edges between nodes) with brand role names for
colour and type. The compiler places everything inside the brand's content area,
measures text with the brand font and fails with the node and the shortfall when
content cannot fit. Text is never shrunk to fit.

A native emitter writes the result directly into a copy of the brand template.
The title fills the layout's own placeholder, labels sit inside their shapes,
arrows are connectors attached to their shapes, cards are native groups and
icons are copied from the brand's library as native geometry. Seven preset
shapes are available. These structures survive an import into Google Slides.

`compose preview` builds the deck, renders it and returns slide images with
findings, so each slide can be seen and revised while its design is fresh. It
renders through Google by default, updating one Drive file named `Preview: …` in
place, or through LibreOffice with `--renderer local`.

The installer now installs the engine's packages and reports the outcome.

Current public guidance requires runtime 0.10.0 and routes new decks to
compositions. Saved tasks retain their older runtime and guidance. Tables,
charts and hyperlinks are not yet available in compositions; the typed
components remain for those.

## Limits

- Arrows attach to `rect`, `roundRect`, `diamond` and `ellipse`. To other
  shapes and to icons they are positioned but not attached, and reported.
- One template layout per deck.
- Icons keep the library's colours.

## Verification

Unit and package tests cover the compiler, emitter, preview and installer,
including a package audit of every emitted part. Decks built against a corporate
template were imported through Drive, exported back and compared, and Google's
renders were inspected by eye. The combined Tart gate was not run for this
release, the output was not opened in PowerPoint, and no deck has yet been
produced by an agent following the new guidance from a plain request.
