# Harness Slides 0.12.0

A deck is now drafted before it is built. The draft settles what the deck says,
on a page the user can see and change in about a minute a round; the build then
draws what was approved. A fresh agent drafted a 25-slide deck in under ten
minutes, where building 18 slides took 25.

## Draft, then build

- **`outline.json`:** each slide's claim, what the audience must understand, the
  relation, the focal point, the points, a caveat, a source and speaker notes.
  No layout.
- **`outline check`:** every structure problem in one run, then findings about
  the words: a title too long for the brand, a slide over its word budget, four
  dense slides in a row, a repeated title, no point named, no speaker notes.
- **`outline draft`:** one self-contained page with every slide as a grey
  wireframe. Local, under a second, no Google and no brand color.
- **`outline start`:** turns an approved outline into the lead's cover, section
  and closing slides, the merge list, a brief file, and one brief per section
  of three or four content slides.
- **`outline contract --brand`:** the format, and what this brand allows a title
  and a slide to hold.

A new deck is routed draft first; the design page is read when the build
starts.

## Slides

- **Furniture:** a content slide can set `subtitle`, `caveat` and `source`. The
  subtitle goes into the template's own title-and-subtitle layout; the caveat is
  a ruled strip at the foot with an optional one-word label; the source is a
  line beneath it.
- **Type range:** a text role whose color the deck direction has given a job is
  drawn in ink, and takes the focal color when it is the slide's point, so the
  big-number role is safe to use. Guidance says when to use each role.
- **Speaker notes:** a slide presented live with no notes is reported.
- **Three at a time:** a serial build writes, checks and previews slides in
  threes.

## Changed behavior

- A content slide may now carry `subtitle`; before, it was refused.
- Under a direction, text in a role colored like the focal or a meaning is
  drawn in ink unless it is the focal node.

Current public guidance requires runtime 0.12.0.

## Verification

Unit tests: 178 pass, 3 skipped; two studio tests need local port binding and
fail only inside a sandbox. A fresh agent drafted a deck from a plain request
and its report drove a round of fixes. Furniture and the type change were
rendered through Google Slides on a brand template and inspected by eye. No
deck has yet been built end to end from an approved outline, batching in
threes is unmeasured, the combined Tart gate was not run, and no output was
opened in PowerPoint.
